# 稽古堂 · 公版文本注释版编辑工具

面向公版古籍整理者的章节、句子和词语级注释工作台。支持脚注、异文、背景说明与交叉引用，并可在阅读版、编辑版、校勘版之间切换，解决不同来源之间的注释冲突。

## 功能

- 按章节、句子和词语选择注释目标，维护脚注、异文、背景说明和交叉引用。
- 使用稳定 ID 保存正文与注释关系；句子修订后，失效的词级引用自动迁移到所属句，避免悬空引用。
- 自动按“引用目标 + 注释类型”汇总来源冲突，可逐条选用来源或合并正文后解决。
- 阅读版按引用展开脚注，编辑版提供正文和注释编辑，校勘版并列展示来源、异文与校记。
- 章节目录跳转、正文/注释/来源全文检索，以及下一条注释快速定位。
- 本地离线草稿自动保存；模拟接口保存按钮用于演示网络保存状态。
- **离线交接包三方合并**：可按组员导出整包（含底本快照）；回内网导入先做**可撤销预演**，确认后才写草稿并自动留合并快照。
  - 新增注释直接接上；两边改过同一注释时**保留双方原文**，自动成组进“冲突”页签由人工逐条选定或合并。
  - 正文或分词变化后，词级注释按词形**跟到同词**；同句找不到则降到所属句并标为**待确认**，可一键确认锚点。
  - 正文以内网稿为准，交接包中的正文改动在预演中逐句列出，不覆盖内网正文。
  - 交接包 ID 为内容指纹：同一包重复导入、断网恢复后再次导入、或同内容重新导出，均自动拦截，绝不重复新增。
  - 合并结果在阅读、校勘、检索、HTML/JSON 导出与版本比较中均带来源与待确认标记。
- 版本快照与两版差异比较，可查看句子改动、新增注释、条文改动与锚点迁移并恢复快照。
- 导出完整 HTML 阅读版或 JSON 数据，支持浏览器打印。
- 快捷键：`J/K` 上/下一条注释，`[`/`]` 上/下句，`/` 聚焦搜索，`Alt+1/2/3` 切换视图，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做，`Ctrl/⌘+S` 模拟接口保存。
- 响应式布局：桌面使用三栏工作区，窄屏自动堆叠；所有主要按钮和编辑目标均有语义标签。

## 技术栈

- Next.js 15（App Router、静态导出）
- React 19
- TypeScript
- HeroUI + Tailwind CSS
- localStorage 离线持久化
- 浏览器内模拟接口，无后端依赖

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的本地地址。开发服务器端口由 Next.js 决定，源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `out/`。由于启用了 `output: 'export'`，不需要 Node.js 服务即可托管。

## Docker

```bash
docker build -t sologsb-1022 .
docker run --rm -p 10022:80 sologsb-1022
```

容器内 nginx 监听 `80`，根端口表将其映射为宿主 `10022`。

## 测试

合并引擎与冲突分组为纯函数，可用 Node 直接验证（不依赖浏览器）：

```bash
npm run test:merge
```

覆盖：三方合并判定（新增/采用/双方冲突/一致跳过/本地较新）、跨机器分词 ID 下的词形跟随与降句待确认、冲突孪生稿成对进入冲突面板、按配对收口的解决流程、同包重复导入与断网恢复后再次导入的幂等拦截、多组员连续合并不串组不翻倍。

## 数据说明

离线草稿、版本快照、交接包导入登记（含内容指纹）和最后编辑位置保存在当前浏览器 `localStorage`。清除站点数据会删除这些内容；导出的 HTML/JSON/交接包可用于外部备份。
